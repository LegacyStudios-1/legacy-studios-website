# Legacy Studios Website

Official website for **Legacy Studios**, an independent game development studio creating immersive 3D games and interactive experiences.

## Featured Project

**PARALLEL** — a multiplayer social adventure where each player experiences a different reality within the same physical world.

## Stack

- HTML
- CSS
- JavaScript
- GitHub Pages

## Local preview

Open `index.html` in a browser or serve the folder with any static HTTP server.

## Deployment

The repository includes a GitHub Actions workflow that deploys the site to GitHub Pages whenever changes are pushed to `main`.

## Domain

Production domain: **https://legacystudios.cloud**
